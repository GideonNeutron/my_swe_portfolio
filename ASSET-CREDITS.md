# Technology artwork

Logos identify the technologies used; they do not imply endorsement. Assets are stored locally.

- Devicon artwork: MIT licensed; see `public/images/tech/DEVICON-LICENSE.txt`.
- Simple Icons artwork: CC0; individual brand guidelines and trademarks still apply.
- Chainlit and HTCondor artwork: from the projects themselves.
- Django AllAuth, Flutter Provider, and Firestore use their parent ecosystem marks. GlideinWMS is represented by the HTCondor ecosystem mark. LLaMA 2 uses the Meta mark. SQL uses a neutral database illustration because SQL is a language standard, not a vendor brand.
